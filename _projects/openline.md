OpenLine is an open-source Python package for modeling overhead transmission lines, calculating line impedance and admittance, conductor ampacity, sag, and tension.

It includes a catalog of conductors and structures drawn from standards and manufacturer documents.
- [Documentation](https://openline.readthedocs.io) via readthedocs
- Available on [PyPI](https://pypi.org/project/openline/)
- Source code on [GitHub](https://github.com/BirchfieldResearchGroup/openline)

The library is free to use to accelerate your research.
