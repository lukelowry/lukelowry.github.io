pyvectorfit is an open-source Python package for vector fitting of delayed pole-residue models in electromagnetic transient (EMT) simulation.

It provides rational fitting, universal line models with searched modal delays, and passivity assessment and enforcement, all on plain NumPy arrays.
- [Documentation](https://pyvectorfit.readthedocs.io) via readthedocs
- Available on [PyPI](https://pypi.org/project/pyvectorfit/)
- Source code on [GitHub](https://github.com/BirchfieldResearchGroup/pyvectorfit)

The library is free to use to accelerate your research.
